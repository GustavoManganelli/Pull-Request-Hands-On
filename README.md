# Pull Request Hands On
> Mentor: Carlos Alberto da Silva Junior

<br>

### O que é o projeto?
O projeto, instruido por nosso professor de DevOps Carlos Alberto, tem como objetivos nos ensinar:
- Pull Requests
- Code Review
- README.md

<br>

### Linguagens utilizadas
Nós utilizamos:
- HTML -> para estruturar nosso website
- CSS -> para estiliza-lo
- JS -> para funcionalidades como a troca de cor do fundo dependendo do personagem

<br>

### Como usar o projeto?
Para rodar esse projeto é bem simples, basta abri-lo em um editor de código como o Visual Studio Code e através de uma extensão como o Live server,
visualizar o arquivo a partir do index.html
